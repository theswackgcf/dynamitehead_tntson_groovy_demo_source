## Welcome to the DYNAMITEHEAD TNTSON: The Groovy Demo's source code repository!

This repository includes two branches: **main** (WINDOWS) and **html**. Each for the respective versions of the game.

It's recommended to clone both branches into a local repository, if you wanna start editing this game's files.

### Enabling debug mode:

Locate the **obj_game** object, head over into its **Create** event, and change **global._debug** from false to true. This allows you to choose from a room list, move anywhere you want, and you get to use the Battlezone Maker. Press **TAB** in-game when debug is enabled for more info.
